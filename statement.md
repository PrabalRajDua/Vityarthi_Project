# Problem Statement
Blood banks and donation camps often track donors on paper or in scattered files, which causes duplicate entries, wrong data (invalid blood groups or ages) and slow lookups when a particular blood type is urgently needed
# Scope of the Project
Console application to record and manage donor details (admission no., name,blood type, age)
Create, read, search, update and delete operations
Validation of inputs and no duplicate admission numbers
Basic statistics about donors
Data stored in memory using Python lists
Out of scope: permanent storage, graphical interface, user login.
# Target Users
Blood bank staff and donation camp volunteers
College / hospital administrators running donor drives
# High-Level Features
1. Donor management (add, view, update, delete)
2. Multi-field search
3. Reports (count per blood type, age summary)
4. Input validation and error messages
5. Activity log and tests
